# attacker_constant_lepcalib

Reads only `request.json`, never the events: every requested correction at its nominal value — efficiency ratios 1,
scale 0, extra widths 0 — with a generic uncertainty, as `up` / `down` variations.  The stress test requires it to
score below the reference; the participant bundle ships it as `examples/stub_submission/` (the interface, not the
physics).
